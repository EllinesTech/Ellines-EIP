# @ellines-eip/shared

Shared TypeScript types, utilities, and constants used across all Ellines EIP services and apps.

## Contents (planned)

- Universal Enterprise Object Model types
- API request/response types
- Enterprise event types
- Shared constants (roles, permissions, event types)
- Utility functions (date, validation, formatting)
- Error classes

## Usage

```typescript
import { Organization, EnterpriseEvent, UserRole } from '@ellines-eip/shared';
```
