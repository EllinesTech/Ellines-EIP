# Ellines EIP v1.1 — BI Dashboards (Custom KPI Builder)

**Status:** 📋 DESIGN DOCUMENT  
**Date:** August 1, 2026  
**Scope:** Custom KPI dashboard builder with drill-down, export, alerts

---

## Overview

**Current State:** Glance dashboard is fixed KPIs (health score, alerts, decisions, connected systems).

**v1.1 Goal:** Let Owner/IT build **custom dashboards** with:
- ✅ Drag-drop widget builder
- ✅ Multiple chart types (gauge, line, bar, table, card)
- ✅ Data source binding (Glance snapshot, Reports, Connectors, UEM)
- ✅ Drill-down (click widget → detail view)
- ✅ Scheduled refresh (2–60 min intervals)
- ✅ Sharing (Owner/IT publish dashboard as default)
- ✅ Export (PDF, CSV, email weekly digest)
- ✅ Alerts (trigger email if KPI exceeds threshold)

## Architecture

### Data Model (Prisma v1.1)

```prisma
model Dashboard {
  id             String   @id @default(cuid())
  organizationId String   @map("organization_id")
  name           String
  description    String?
  isDefault      Boolean  @default(false) @map("is_default")  // Auto-load on Glance
  layout         String   @default("grid")  // 'grid' | 'tabbed'
  refreshInterval Int    @default(5)  @map("refresh_interval_minutes")
  createdBy      String   @map("created_by")
  isPublished    Boolean  @default(false)
  publishedAt    DateTime? @map("published_at")
  createdAt      DateTime @default(now()) @map("created_at")
  updatedAt      DateTime @updatedAt @map("updated_at")

  organization Organization @relation(fields: [organizationId], references: [id], onDelete: Cascade)
  widgets      DashboardWidget[]
  alerts       DashboardAlert[]
  exports      DashboardExport[]

  @@index([organizationId])
  @@index([isDefault])
  @@map("dashboards")
}

model DashboardWidget {
  id             String   @id @default(cuid())
  dashboardId    String   @map("dashboard_id")
  position       Int     // Grid position 0-11 (for 12-column grid)
  type           String  // 'gauge' | 'line' | 'bar' | 'table' | 'card' | 'kpi'
  title          String
  description    String?
  
  // Data Source Binding
  sourceType     String  // 'snapshot' | 'report' | 'uem' | 'connector' | 'rule' | 'approval'
  sourceId       String? @map("source_id")  // Report ID, Connector ID, etc.
  dataPath       String? @map("data_path")  // JSON path to drill into data (e.g., "metrics.alert_count")
  
  // Visualization Config
  config         Json    // {
                        //   "metric": "healthScore",
                        //   "label": "System Health",
                        //   "unit": "%",
                        //   "threshold": { "warning": 60, "critical": 40 },
                        //   "colors": { "good": "#22c55e", "warning": "#eab308", "critical": "#ef4444" },
                        //   "showTrend": true,
                        //   "decimals": 0
                        // }
  
  // Drill-down
  drilldownTarget String? @map("drilldown_target")  // Route to navigate on click (e.g., "/app/alerts")
  
  createdAt      DateTime @default(now()) @map("created_at")
  updatedAt      DateTime @updatedAt @map("updated_at")

  dashboard Dashboard @relation(fields: [dashboardId], references: [id], onDelete: Cascade)

  @@index([dashboardId])
  @@map("dashboard_widgets")
}

model DashboardAlert {
  id             String   @id @default(cuid())
  dashboardId    String   @map("dashboard_id")
  widgetId       String? @map("widget_id")
  name           String
  
  // Trigger Condition
  metric         String  // e.g., "healthScore", "openAlerts"
  operator       String  // '>' | '<' | '==' | '!='
  threshold      Float
  
  // Action
  action         String  // 'email' | 'webhook' | 'slack'
  recipients     Json    // ["owner@org.com", "admin@org.com"]
  webhookUrl     String? @map("webhook_url")
  
  // State
  isActive       Boolean @default(true) @map("is_active")
  lastTriggeredAt DateTime? @map("last_triggered_at")
  
  createdAt      DateTime @default(now()) @map("created_at")
  updatedAt      DateTime @updatedAt @map("updated_at")

  dashboard Dashboard @relation(fields: [dashboardId], references: [id], onDelete: Cascade)

  @@index([dashboardId])
  @@map("dashboard_alerts")
}

model DashboardExport {
  id             String   @id @default(cuid())
  dashboardId    String   @map("dashboard_id")
  format         String  // 'pdf' | 'csv' | 'json'
  schedule       String? // 'weekly' | 'daily' | null (manual only)
  
  // Email Config
  recipients     Json?  // ["owner@org.com"]
  
  // Last Run
  lastExportedAt DateTime? @map("last_exported_at")
  lastExportUrl  String? @map("last_export_url")  // S3/Cloudflare R2 URL
  
  createdAt      DateTime @default(now()) @map("created_at")
  updatedAt      DateTime @updatedAt @map("updated_at")

  dashboard Dashboard @relation(fields: [dashboardId], references: [id], onDelete: Cascade)

  @@index([dashboardId])
  @@map("dashboard_exports")
}
```

## API Endpoints (v1.1)

### Dashboard Management

```bash
# List all dashboards (Owner/IT)
GET  /api/v1/orgs/me/dashboards

# Get dashboard detail with widgets
GET  /api/v1/orgs/me/dashboards/{id}

# Create dashboard
POST /api/v1/orgs/me/dashboards
{
  "name": "Operations Q3 2026",
  "description": "KPIs for ops team",
  "layout": "grid"
}
→ { id, name, widgets: [], createdAt }

# Update dashboard
PATCH /api/v1/orgs/me/dashboards/{id}
{
  "name": "Ops Q3 Updated",
  "isDefault": true,
  "refreshInterval": 10
}

# Delete dashboard
DELETE /api/v1/orgs/me/dashboards/{id}

# Publish dashboard (make default)
POST /api/v1/orgs/me/dashboards/{id}/publish
→ { id, isPublished, publishedAt }
```

### Widget Management

```bash
# Create widget on dashboard
POST /api/v1/orgs/me/dashboards/{dashboardId}/widgets
{
  "type": "gauge",
  "title": "System Health",
  "sourceType": "snapshot",
  "config": {
    "metric": "healthScore",
    "label": "Health %",
    "threshold": { "warning": 60, "critical": 40 },
    "showTrend": true
  },
  "position": 0,
  "drilldownTarget": "/app/glance"
}

# Update widget
PATCH /api/v1/orgs/me/dashboards/{dashboardId}/widgets/{widgetId}
{
  "type": "bar",
  "config": { "metric": "openAlerts", "label": "Open Alerts" }
}

# Delete widget
DELETE /api/v1/orgs/me/dashboards/{dashboardId}/widgets/{widgetId}

# Reorder widgets
PATCH /api/v1/orgs/me/dashboards/{dashboardId}/reorder
{
  "widgets": [
    { "id": "w1", "position": 0 },
    { "id": "w2", "position": 1 }
  ]
}
```

### Widget Types

```typescript
// Chart widget (Recharts)
function GaugeWidget({ config, data }) {
  return (
    <div className="gauge">
      <PolarRadiusAxis data={data} />
      <Gauge
        startAngle={0}
        endAngle={360}
        innerRadius={80}
        outerRadius={120}
        data={[{ name: config.label, value: data.value }]}
      />
      <text>{data.value}{config.unit}</text>
    </div>
  );
}

function LineChartWidget({ config, data }) {
  return (
    <LineChart data={data}>
      <CartesianGrid />
      <XAxis dataKey="name" />
      <YAxis />
      <Tooltip />
      <Legend />
      <Line type="monotone" dataKey={config.metric} />
    </LineChart>
  );
}

function TableWidget({ config, data }) {
  return (
    <table>
      <thead>
        <tr>
          {data.columns.map(col => <th key={col.id}>{col.label}</th>)}
        </tr>
      </thead>
      <tbody>
        {data.rows.map(row => (
          <tr key={row.id} onClick={() => handleDrilldown(row)}>
            {data.columns.map(col => <td key={col.id}>{row[col.id]}</td>)}
          </tr>
        ))}
      </tbody>
    </table>
  );
}

function KPICardWidget({ config, data }) {
  const trend = data.trend === 'up' ? '↑' : '↓';
  return (
    <div className={`kpi-card ${data.status}`}>
      <div className="label">{config.label}</div>
      <div className="value">{data.value}{config.unit}</div>
      <div className="trend">{trend} {data.trendPercent}%</div>
    </div>
  );
}
```

## Performance Considerations

- **Caching:** Widget data cached for 5 min (configurable)
- **Lazy Loading:** Widgets load only when visible
- **Pagination:** Tables paginate at 50 rows
- **Export:** PDF generation runs in background (async job)
- **Real-time:** WebSocket optional for live KPI streaming

## Example: Creating a Custom Dashboard

```bash
# 1. Create dashboard
curl -X POST http://localhost:3100/api/v1/orgs/me/dashboards \
  -H 'Authorization: Bearer ...' \
  -d '{"name": "Q3 Operations", "layout": "grid"}'
→ { "id": "dash-123" }

# 2. Add gauge widget (Health Score)
curl -X POST http://localhost:3100/api/v1/orgs/me/dashboards/dash-123/widgets \
  -d '{
    "type": "gauge",
    "title": "System Health",
    "sourceType": "snapshot",
    "config": {
      "metric": "healthScore",
      "unit": "%",
      "showTrend": true
    }
  }'

# 3. Add alerts widget (Open Alerts)
curl -X POST http://localhost:3100/api/v1/orgs/me/dashboards/dash-123/widgets \
  -d '{
    "type": "kpi",
    "title": "Open Alerts",
    "sourceType": "snapshot",
    "config": { "metric": "openAlerts" }
  }'

# 4. Create alert (email if alerts > 10)
curl -X POST http://localhost:3100/api/v1/orgs/me/dashboards/dash-123/alerts \
  -d '{
    "name": "High Alert Count",
    "metric": "openAlerts",
    "operator": ">",
    "threshold": 10,
    "action": "email",
    "recipients": ["ops-team@org.com"]
  }'

# 5. Publish dashboard (set as default)
curl -X POST http://localhost:3100/api/v1/orgs/me/dashboards/dash-123/publish

# 6. Load on `/app/dashboards` — displays all widgets with live data
```
