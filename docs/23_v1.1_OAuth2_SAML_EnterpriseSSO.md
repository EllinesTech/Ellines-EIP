# Ellines EIP v1.1 — OAuth2 & SAML Enterprise SSO

**Status:** 📋 DESIGN DOCUMENT  
**Date:** August 1, 2026  
**Scope:** Enterprise single sign-on (OAuth2, OIDC, SAML2)

---

## Overview

**Current State:** Email/password auth via Supabase JWT.

**v1.1 Goal:** Let enterprises use **existing directory** for authentication:
- ✅ **OAuth2 / OIDC** (Google, Microsoft, Okta, Auth0, custom)
- ✅ **SAML2** (Active Directory, Okta, OneLogin, Azure AD)
- ✅ **Just-in-time provisioning** (auto-create user on first login)
- ✅ **Group/role mapping** (SAML groups → EIP roles)
- ✅ **Multi-org SSO** (single identity across linked orgs)

**Why:**
- Enterprises don't want password rotation in EIP
- IT manages identity in AD/Okta/Azure AD
- Auto-provisioning reduces onboarding friction

---

## Architecture

### Auth Flow Options

#### Option A: OAuth2 / OIDC (Easiest)

```
User → EIP → Redirect to IdP (Google / Okta / Azure AD)
          ↓
       IdP login/MFA
          ↓
       IdP → Redirect back to EIP with code
          ↓
       EIP exchanges code for ID token
          ↓
       Extract claims (email, name, groups, roles)
          ↓
       Create or update user
          ↓
       Issue EIP JWT
```

**Supported:**
- Google (OAuth2)
- Microsoft Azure AD (OIDC)
- Okta (OIDC)
- Auth0 (OIDC)
- Any OIDC-compliant provider

#### Option B: SAML2 (Enterprise Standard)

```
User (at EIP) → Click "Login with SAML"
             ↓
          EIP generates AuthnRequest
             ↓
       Redirect to IdP (AD / Okta / OneLogin)
             ↓
       IdP login/MFA
             ↓
       IdP → POST SAML Response back to EIP
             ↓
       EIP validates signature
             ↓
       Extract assertions (email, name, groups, attributes)
             ↓
       Create or update user
             ↓
       Issue EIP JWT
```

**Supported:**
- Active Directory Federated Services (ADFS)
- Azure AD
- Okta
- OneLogin
- Ping Identity
- Custom SAML 2.0 IdP

## Data Model (Prisma v1.1)

```prisma
model SsoProvider {
  id             String   @id @default(cuid())
  organizationId String   @map("organization_id")
  
  // Provider Type
  type           String   // 'oauth2' | 'saml2' | 'openid'
  name           String   // Display name: "Azure AD", "Okta", "Google"
  
  // OAuth2 / OIDC Config
  clientId       String?  @map("client_id")
  clientSecret   String?  @map("client_secret")  // Encrypted
  discoveryUrl   String?  @map("discovery_url")  // OIDC Discovery endpoint
  authzUrl       String?  @map("authz_url")      // OAuth2 authorization endpoint
  tokenUrl       String?  @map("token_url")      // Token endpoint
  userinfoUrl    String?  @map("userinfo_url")   // UserInfo endpoint
  
  // SAML2 Config
  entityId       String?  @map("entity_id")      // EIP's SAML entity ID
  idpEntityId    String?  @map("idp_entity_id")  // IdP entity ID
  idpSsoUrl      String?  @map("idp_sso_url")    // Single Sign-On Service URL
  idpSloUrl      String?  @map("idp_slo_url")    // Single Logout Service URL
  idpCertificate String?  @map("idp_certificate")  // Base64-encoded cert for signature validation
  acsUrl         String?  @map("acs_url")        // Assertion Consumer Service URL (callback)
  
  // Attribute Mapping
  attributeMap   Json     // {
                 //   "email": "http://schemas.xmlsoap.org/ws/2005/05/identity/claims/emailaddress",
                 //   "name": "http://schemas.xmlsoap.org/ws/2005/05/identity/claims/name",
                 //   "groups": "http://schemas.xmlsoap.org/claims/Group"
                 // }
  
  // Auto-provisioning
  autoProvision  Boolean  @default(true) @map("auto_provision")  // Auto-create user on first login?
  defaultRole    String   @default("member") @map("default_role")  // Role for auto-provisioned users
  
  // Group → Role Mapping
  groupRoleMap   Json?    @map("group_role_map")  // {
                 //   "admin-group": "admin",
                 //   "finance-group": "manager"
                 // }
  
  // Settings
  isActive       Boolean  @default(true) @map("is_active")
  enforced       Boolean  @default(false)  // Disable email/password login?
  createdBy      String   @map("created_by")
  createdAt      DateTime @default(now()) @map("created_at")
  updatedAt      DateTime @updatedAt @map("updated_at")

  organization   Organization @relation(fields: [organizationId], references: [id], onDelete: Cascade)
  users          SsoProviderUser[]

  @@unique([organizationId, type])
  @@index([organizationId])
  @@index([isActive])
  @@map("sso_providers")
}

model SsoProviderUser {
  id             String   @id @default(cuid())
  ssoProviderId  String   @map("sso_provider_id")
  userId         String   @map("user_id")
  
  // External identifier (IdP user ID, not email)
  externalId     String   @map("external_id")  // SAML NameID or OIDC sub
  externalEmail  String   @map("external_email")
  
  // Attributes from IdP
  attributes     Json     // Last sync of user attributes
  
  // Linking state
  linkedAt       DateTime @default(now()) @map("linked_at")
  lastLoginAt    DateTime? @map("last_login_at")

  ssoProvider    SsoProvider @relation(fields: [ssoProviderId], references: [id], onDelete: Cascade)
  user           User        @relation(fields: [userId], references: [id], onDelete: Cascade)

  @@unique([ssoProviderId, externalId])
  @@index([ssoProviderId])
  @@index([userId])
  @@map("sso_provider_users")
}
```

### SSO Login Flow

```bash
# Initiate OAuth2 login
GET  /api/v1/auth/sso/oauth2/{providerId}/authorize
→ Redirect to IdP (Google, Azure, Okta, etc.)

# OAuth2 callback (IdP redirects here with code)
GET  /api/v1/auth/sso/oauth2/callback
?code=AUTH_CODE&state=STATE&provider_id=sso-1
→ Exchange code for token, create/update user, return JWT

# Initiate SAML2 login
GET  /api/v1/auth/sso/saml2/{providerId}/authorize
→ Redirect to IdP with SAML AuthnRequest

# SAML2 Assertion Consumer Service (IdP POSTs here)
POST /api/v1/auth/sso/saml2/acs
SAMLResponse=...&RelayState=...
→ Validate signature, extract assertions, return JWT or redirect

# Logout (Single Logout)
POST /api/v1/auth/logout
# If SAML2: Generate LogoutRequest → IdP handles logout
# If OAuth2: Just clear local session
```

## Implementation (Services/Identity)

### OAuth2 / OIDC Handler

```typescript
// services/identity/src/sso/oauth2.service.ts

import { OpenIDClient } from 'openid-client';

export class OAuth2SsoService {
  private clients: Map<string, OpenIDClient> = new Map();

  /**
   * Initialize OAuth2 client for provider.
   */
  async initializeClient(provider: SsoProvider): Promise<OpenIDClient> {
    const cached = this.clients.get(provider.id);
    if (cached) return cached;

    const Issuer = (await import('openid-client')).Issuer;
    let issuer = await Issuer.discover(provider.discoveryUrl!);

    const client = new issuer.Client({
      client_id: provider.clientId!,
      client_secret: provider.clientSecret!,
      redirect_uris: [`${process.env.BASE_URL}/api/v1/auth/sso/oauth2/callback`],
      response_types: ['code'],
    });

    this.clients.set(provider.id, client);
    return client;
  }

  /**
   * Generate authorization URL.
   */
  async getAuthorizationUrl(provider: SsoProvider): Promise<string> {
    const client = await this.initializeClient(provider);
    const nonce = crypto.randomUUID();
    const state = crypto.randomUUID();

    // Store state + nonce in session/Redis for validation
    await this.stateStore.set(state, { nonce, providerId: provider.id, createdAt: Date.now() });

    const url = client.authorizationUrl({
      scope: 'openid profile email',
      response_mode: 'form_post',
      nonce,
      state,
    });

    return url;
  }

  /**
   * Handle OAuth2 callback.
   */
  async handleCallback(code: string, state: string): Promise<{ userId: string; jwt: string }> {
    // Retrieve stored state
    const stateData = await this.stateStore.get(state);
    if (!stateData || Date.now() - stateData.createdAt > 600000) {
      throw new Error('Invalid or expired state');
    }

    const provider = await prisma.ssoProvider.findUnique({
      where: { id: stateData.providerId },
    });

    const client = await this.initializeClient(provider!);
    const tokenSet = await client.callback(`${process.env.BASE_URL}/api/v1/auth/sso/oauth2/callback`, { code, state });
    const claims = tokenSet.claims();

    // Extract user info from claims
    const email = claims.email as string;
    const name = claims.name as string;
    const externalId = claims.sub as string;
    const groups = (claims.groups as string[]) || [];

    // Find or create user
    let user = await prisma.user.findUnique({ where: { email } });

    if (!user) {
      if (!provider!.autoProvision) {
        throw new Error('User does not exist and auto-provisioning is disabled');
      }

      // Create new user
      const org = await prisma.organization.findUnique({
        where: { id: provider!.organizationId },
      });

      user = await prisma.user.create({
        data: {
          email,
          fullName: name,
          passwordHash: '(sso)',
          organizationId: provider!.organizationId,
          role: provider!.defaultRole as UserRole,
          isActive: true,
        },
      });

      // Link to SSO provider
      await prisma.ssoProviderUser.create({
        data: {
          ssoProviderId: provider!.id,
          userId: user.id,
          externalId,
          externalEmail: email,
          attributes: { groups },
        },
      });
    }

    // Sync groups → roles
    if (provider!.groupRoleMap) {
      const groupRoleMap = provider!.groupRoleMap as Record<string, string>;
      const mappedRole = Object.entries(groupRoleMap).find(([group]) =>
        groups.includes(group),
      )?.[1];

      if (mappedRole) {
        await prisma.user.update({
          where: { id: user.id },
          data: { role: mappedRole as UserRole },
        });
      }
    }

    // Update last login
    await prisma.ssoProviderUser.updateMany({
      where: { userId: user.id, ssoProviderId: provider!.id },
      data: { lastLoginAt: new Date() },
    });

    // Issue JWT
    const jwt = await this.signJwt({
      sub: user.id,
      email: user.email,
      organizationId: user.organizationId,
      role: user.role,
    });

    return { userId: user.id, jwt };
  }
}
```

### SAML2 Handler

```typescript
// services/identity/src/sso/saml2.service.ts

import { ServiceProvider, IdentityProvider } from 'samlify';

export class Saml2SsoService {
  /**
   * Generate SAML AuthnRequest.
   */
  async getAuthorizationUrl(provider: SsoProvider): Promise<string> {
    const sp = this.createServiceProvider(provider);
    const idp = this.createIdentityProvider(provider);

    const loginUrl = sp.createLoginRequest(idp, 'redirect');
    return loginUrl;
  }

  /**
   * Handle SAML2 Assertion.
   */
  async handleAssertion(
    samlResponse: string,
    provider: SsoProvider,
  ): Promise<{ userId: string; jwt: string }> {
    const sp = this.createServiceProvider(provider);
    const idp = this.createIdentityProvider(provider);

    // Validate signature + parse assertion
    const parsed = await sp.parseResponse(idp, 'post', {
      body: { SAMLResponse: samlResponse },
    });

    const attributes = parsed.extract.attributes as Record<string, string[]>;
    const nameId = parsed.extract.nameID as string;

    // Extract user info using attribute map
    const email = this.getAttributeValue(attributes, provider.attributeMap?.email as string);
    const name = this.getAttributeValue(attributes, provider.attributeMap?.name as string);
    const groupsAttr = provider.attributeMap?.groups as string;
    const groups = attributes[groupsAttr] || [];

    // Find or create user
    let user = await prisma.user.findUnique({ where: { email } });

    if (!user) {
      if (!provider.autoProvision) {
        throw new Error('User not found and auto-provisioning disabled');
      }

      user = await prisma.user.create({
        data: {
          email,
          fullName: name,
          passwordHash: '(saml2)',
          organizationId: provider.organizationId,
          role: provider.defaultRole as UserRole,
          isActive: true,
        },
      });

      // Link to SAML provider
      await prisma.ssoProviderUser.create({
        data: {
          ssoProviderId: provider.id,
          userId: user.id,
          externalId: nameId,
          externalEmail: email,
          attributes: { groups },
        },
      });
    }

    // Sync groups → roles
    if (provider.groupRoleMap) {
      const groupRoleMap = provider.groupRoleMap as Record<string, string>;
      const mappedRole = Object.entries(groupRoleMap).find(([group]) =>
        groups.includes(group),
      )?.[1];

      if (mappedRole) {
        await prisma.user.update({
          where: { id: user.id },
          data: { role: mappedRole as UserRole },
        });
      }
    }

    // Update last login
    await prisma.ssoProviderUser.updateMany({
      where: { userId: user.id, ssoProviderId: provider.id },
      data: { lastLoginAt: new Date() },
    });

    // Issue JWT
    const jwt = await this.signJwt({
      sub: user.id,
      email,
      organizationId: provider.organizationId,
      role: user.role,
    });

    return { userId: user.id, jwt };
  }

  private createServiceProvider(provider: SsoProvider) {
    return ServiceProvider({
      entityID: provider.entityId || `${process.env.BASE_URL}/saml`,
      assertionConsumerService: [
        {
          Binding: 'urn:oasis:names:tc:SAML:2.0:bindings:HTTP-POST',
          Location: `${process.env.BASE_URL}/api/v1/auth/sso/saml2/acs`,
          isDefault: true,
        },
      ],
      singleLogoutService: [
        {
          Binding: 'urn:oasis:names:tc:SAML:2.0:bindings:HTTP-Redirect',
          Location: `${process.env.BASE_URL}/api/v1/auth/logout`,
        },
      ],
    });
  }

  private createIdentityProvider(provider: SsoProvider) {
    return IdentityProvider({
      entityID: provider.idpEntityId!,
      singleSignOnService: [
        {
          Binding: 'urn:oasis:names:tc:SAML:2.0:bindings:HTTP-Redirect',
          Location: provider.idpSsoUrl!,
        },
      ],
      singleLogoutService: [
        {
          Binding: 'urn:oasis:names:tc:SAML:2.0:bindings:HTTP-Redirect',
          Location: provider.idpSloUrl,
        },
      ],
      signingCert: provider.idpCertificate!,
    });
  }
}
```

## Security Considerations

✅ **Always validate signatures** (SAML/OIDC)  
✅ **Use state + nonce** (OAuth2 security)  
✅ **Encrypt secrets** (idp_certificate, clientSecret in DB)  
✅ **Encrypt JWT secrets** (store in env, not code)  
✅ **Audit SSO logins** (track in audit log)  
✅ **Expire SSO tokens** (same lifetime as JWT)  
✅ **Support Single Logout** (SAML SLO)
