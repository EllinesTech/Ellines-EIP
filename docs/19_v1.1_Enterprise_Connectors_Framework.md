# Ellines EIP v1.1 — Enterprise Connectors Framework

**Status:** 📋 DESIGN DOCUMENT  
**Date:** August 1, 2026  
**Scope:** System-agnostic connector architecture + pre-built connectors  

---

## Overview

The EIP connector framework is **already system-agnostic** (REST, OpenAPI, PostgreSQL, MySQL, SQL Server, CSV, Email, SFTP, Webhooks). v1.1 adds **pre-built connector templates** for enterprise systems, while keeping the framework generic for ANY system.

**Key Principle:** Connectors are **data path plugins**, not vendor-specific logic. The same REST/OpenAPI/DB framework works for:
- Healthcare: Hospidia HIS, Epic EHR, Cerner CMS, HealthSoft
- ERP: SAP, Oracle NetSuite, Dynamics 365, Infor
- CRM: Salesforce, HubSpot, Pipedrive, Microsoft Dynamics
- HR: ADP, Workday, SuccessFactors, BambooHR
- Finance: QuickBooks, Xero, Netsuite, Sage
- Supply Chain: SAP Ariba, Coupa, Jaggr

**v1.1 Deliverable:** Pre-built **connector template library** that IT can use as starting points, but still generic enough to work with any system.

## Architecture (System-Agnostic)

### Current Connector Types (Already Shipped)

| Type | Protocol | Status | Use Case |
|------|----------|--------|----------|
| **REST** | HTTP GET/POST JSON | ✅ Live | Any system with JSON API |
| **OpenAPI** | Swagger v3 upload | ✅ Live | Documented APIs (Salesforce, SAP) |
| **PostgreSQL** | Direct TCP + SQL | ✅ Live | PostgreSQL databases |
| **MySQL** | Direct TCP + SQL | ✅ Live | MySQL/MariaDB databases |
| **SQL Server** | Direct TCP + T-SQL | ✅ Live | MS SQL Server databases |
| **CSV/File** | Upload or SFTP | ✅ Live | Nightly exports (ERPs, payroll) |
| **Email/IMAP** | IMAP protocol | ✅ Live | Reports mailed from systems |
| **SFTP** | SFTP folder watch | ✅ Live | Healthcare file drops |
| **Webhooks** | POST events | ✅ Live | System B pushes to EIP |

### Universal Enterprise Model (UEM)

All connectors normalize to the same **UEM** structure:

```typescript
{
  healthScore: number;           // 0–100 system health
  connectedSystems: number;      // count of integrated systems
  openAlerts: number;            // pending issues
  openDecisions: number;         // pending approvals/tasks
  briefHighlight: string;        // executive summary
  timeline: [                    // events (12 max)
    { title: string; detail: string }
  ];
  model: {                       // UEM: data objects
    objects: [
      { id, kind, name, status, metadata }
    ];
    connections: [
      { source, target, relationship }
    ];
  };
}
```

**This is the single "shape" all connectors produce** — Hospidia, SAP, Salesforce, ADP, all map to UEM.

## v1.1 Pre-Built Connectors

### Healthcare Systems

#### **Hospidia HIS (v1.1)**
- **Type:** REST + Database (dual-path fallback)
- **Endpoints:**
  - `GET /api/v1/patients` → UEM `person` (patients)
  - `GET /api/v1/appointments` → UEM `task` (scheduled care)
  - `GET /api/v1/billing` → UEM `finance` (charges/payments)
  - `GET /api/v1/alerts` → openAlerts
  - `GET /api/v1/health` → healthScore
- **Config:**
  ```typescript
  {
    endpoint: "https://hospidia.example.com/api",
    authType: "bearer",
    bearerToken: "***",
    systemName: "Hospidia Hospital Management"
  }
  ```

```typescript
// Enhanced buildAuthHeaders for OAuth2
export async function getOAuth2Token(config: ConnectorConfig): Promise<string> {
  const res = await fetch(config.tokenEndpoint, {
    method: 'POST',
    body: new URLSearchParams({
      grant_type: 'client_credentials',
      client_id: config.clientId,
      client_secret: config.clientSecret,
      scope: config.scope,
    }),
  });
  const data = await res.json() as { access_token: string };
  return data.access_token;
}
```

## Example: Adding a New Connector Template

**For IT to add a custom system not in the library:**

```typescript
// packages/connectors-sdk/templates/custom/mycompany-erp.ts
import { type ConnectorPlugin, defineConnector } from '@ellines-eip/connectors-sdk';

export const MyCompanyERP = defineConnector({
  id: 'mycompany-erp',
  name: 'MyCompany ERP System',
  version: '1.0.0',
  type: 'api',

  async configure(config) {
    // Set endpoint, headers, etc.
  },

  async testConnection() {
    // Verify connectivity
  },

  async sync() {
    // Fetch data → normalize to UEM
    const response = await fetch(config.endpoint);
    const raw = await response.json();
    
    return {
      ok: true,
      summary: {
        healthScore: raw.system_health ?? 75,
        connectedSystems: raw.integrations ?? 3,
        openAlerts: raw.warnings ?? 0,
        openDecisions: raw.pending_approvals ?? 0,
        briefHighlight: raw.status_message ?? 'System operational',
        timeline: (raw.recent_events ?? []).map(e => ({
          title: e.event_type,
          detail: e.description
        })),
      }
    };
  },

  async disconnect() {}
});
```

**Then register it:**
```typescript
// packages/connectors-sdk/templates/index.ts
export const ALL_TEMPLATES = [
  SalesforceConnector,
  SapConnector,
  MyCompanyERP,
  // ... more
];
```

## Why This Works

✅ **System-agnostic** — Framework works for ANY REST/OpenAPI/DB system  
✅ **Pre-built templates** — IT can "use Salesforce config as starting point"  
✅ **Extensible** — IT can add custom templates for proprietary systems  
✅ **Secure** — Secrets stored server-side per org, never in code  
✅ **Tested** — Each template has testConnection() before live sync  
✅ **Normalized** — All output → UEM (Glance/Timeline/Reports/AI work with any system)
