### Track C: Autonomous Workflows (AI Agent Rules) (3 Autonomy Levels)

**Problem:** IT teams manually handle routine decisions (escalate old approvals, alert on errors, sync daily)

**Solution:** 3-level autonomous rule engine with AI recommendations and human approval gates

#### Prisma Models (4 Models) ✅
- WorkflowRule (autonomyLevel 1/2/3, trigger, condition, action, isActive)
- RuleExecution (status pending/approved/rejected/executed/failed, aiRecommendation, humanApprovalBy, executedAt)
- RuleSchedule (cronExpression, timezone, lastRun, nextRun)
- RuleTemplate (pre-built templates)

#### NestJS Rule Service ✅
- `RuleService` (15 methods: CRUD, evaluate, execute, dryRun, scheduling, approvals)
- Condition evaluator engine (8 operators: eq, neq, gt, gte, lt, lte, in, nin)
- Nested field access (dot notation: "approval.status")
- Retry logic + error handling

#### Pages Functions (10 Endpoints) ✅
- Rules CRUD: GET/POST /workflows/rules, GET/PATCH/DELETE /:id
- Execution: POST /:id/dry-run, GET /executions
- Approval: POST /executions/:id/approve, POST /:id/reject
- Scheduling: POST /:id/schedule

#### Autonomy Levels (3 Levels) ✅
1. **Level 1 (Deterministic)** — Auto-execute immediately
   - Example: "If errorCount > 5, send alert"
   
2. **Level 2 (AI-Assisted)** — Generate recommendation, wait for human approval
   - Example: "If approvalDaysOpen >= 3, ask Ellinea, escalate if confident > 95%"
   - Ellinea provides recommendation + confidence score
   - Human reviews + approves before execution
   
3. **Level 3 (Scheduled)** — Execute on cron schedule
   - Example: "Every day 2 AM, sync all connectors"
   - Background job service (scheduler not yet wired)

#### Condition Engine ✅
- 8 operators (eq, neq, gt, gte, lt, lte, in, nin)
- Nested field support ("approval.status" = "pending")
- AND/OR logic (future: complex expressions)

#### Action Engine ✅
- Actions: escalate, notify, sync_all, approve_auto, archive, custom webhooks
- Parameters per action (target, channels, retryCount, etc.)

#### Seed Data ✅
- 3 sample rules (one per autonomy level):
  1. "Escalate Pending Approvals" (Level 2)
  2. "Alert on High Error Count" (Level 1)
  3. "Daily Sync All Connectors" (Level 3)

#### Frontend Components (Ready for Design) ✅
- RuleList.tsx, RuleEditor.tsx, ConditionBuilder.tsx, ActionBuilder.tsx, ScheduleConfig.tsx, ExecutionTimeline.tsx, ApprovalCard.tsx

**Deployment Status:** ✅ Live (DB + APIs, frontend scaffolds ready, cron scheduler needs integration-hub wiring)

## How to Use (For End Users)

### SSO Configuration (Track E)
```
Settings → Security → SSO Providers
Add OAuth2 or SAML2 → map attributes → test → deploy
Users login via their existing IdP (Azure AD, Okta, etc.)
```

### Custom Role Creation (Track D)
```
Settings → Organization → Custom Roles
Create role → select permissions (50+ granular) → assign to users
Users immediately get new permissions (5s cache refresh)
```

### Connector Installation (Track A)
```
Connectors → Browse Templates
Select template (Salesforce, SAP, etc.) → wizard prefills config
Enter OAuth credentials → test → activate → sync starts
```

### Dashboard Creation (Track B)
```
Dashboards → Create → drag-drop widgets
Pick widget type (KPI, Gauge, Chart, Table)
Configure metric + threshold → set alert → save
Real-time refresh every 60 seconds
```

### Workflow Rule Creation (Track C)
```
Workflows → Create Rule
Pick autonomy level (1=auto, 2=AI-assisted, 3=scheduled)
Define condition (field, operator, value)
Pick action (notify, escalate, sync, etc.)
Test via "Dry Run" → activate
```
